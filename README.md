# 🛡️ NIGRANI AI

## AI-Powered Smart Public Funds Monitoring Platform

> **Monitor smarter. Verify with evidence. Act with confidence.**

Nigrani AI is an AI-powered monitoring platform designed to help authorities identify potential anomalies, inefficiencies, inconsistencies, and risks in government-funded projects by combining data from multiple sources into one unified system.

---

## 🚨 Problem

Government projects generate information across multiple portals, documents, images, payment records, and other sources.

Checking all this information manually makes it difficult to quickly identify:

- Delayed projects
- Inconsistent records
- Suspicious spending patterns
- False or incomplete claims
- Mismatch in reported project progress
- High-risk projects requiring verification

Nigrani AI addresses this challenge by connecting the complete monitoring process into one intelligent platform.

---

## 💡 Solution

Nigrani AI collects, processes, validates, and analyzes project data from multiple sources using:

- Artificial Intelligence
- Machine Learning
- Computer Vision
- OCR
- Geospatial Analysis
- Multi-source Data Correlation

The system detects potential risks and provides evidence-based insights so that authorized officials can review, verify, and take appropriate action.

### Core Workflow

```text
Official Data
      ↓
Data Collection
      ↓
Data Cleaning
      ↓
Data Extraction
      ↓
Cross-Source Validation
      ↓
AI Analysis
      ↓

      ↓
Evidence-Based Insights
      ↓
Human Review
      ↓
Verify → Act → Monitor
```

## 🔄 How It Works

### 1. Data Collection

Data is collected from official sources through APIs, web scraping, and scheduled updates.

### 2. Data Cleaning

Raw data is cleaned, standardized, and prepared for further processing.

### 3. Data Extraction

Important information is extracted from documents, tables, and images using OCR and parsing techniques.

### 4. Validation & Mapping

Information from different sources is cross-verified to identify inconsistencies.

### 5. Unified Project Database

Validated project data is stored in a structured and centralized database.

### 6. AI Analysis

Machine learning, computer vision, OCR, and geospatial techniques are used to analyze the project data.

### 7. Risk Detection

The platform identifies potential anomalies and generates risk-based insights.

### 8. Evidence Generation

Relevant data and supporting evidence are shown with the detected risk.

### 9. Human Verification

Authorized officials review the information and make the final decision.
